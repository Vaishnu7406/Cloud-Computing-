# Machine Learning-Based Indoor Position Estimation Using Visible-Light Signal Fingerprints

A Streamlit dashboard that predicts an indoor position (X, Y in metres) from the signal strengths
measured from several LED light sources (L1 to L4). It is an **offline software prototype**: signal
values are entered manually. There is no LiFi hardware or live sensor connection.

## Important: the dataset is synthetic
No network access was available when this project was built, so no public dataset could be downloaded.
The bundled dataset (`data/lifi_synthetic_dataset.csv`) is **synthetic**, generated by `data_utils.py`
from a physical simulation, and is **not real experimental data**. Metrics computed on it show that the
software pipeline works; they say nothing about real-world positioning accuracy.

| Item | Value |
|---|---|
| Features | `L1`..`L4`: received optical power from each of 4 ceiling LEDs, in uW (relative units) |
| Targets | `X`, `Y`: receiver position in metres |
| Room (simulated) | 5 m x 5 m, LEDs at (1.25,1.25), (1.25,3.75), (3.75,1.25), (3.75,3.75), ceiling 3 m, receiver at 0.85 m |
| Model | Lambertian line-of-sight (order 1), 100 uW peak, ~3 % multiplicative + 0.3 uW additive noise |
| Samples | 5000 uniformly random positions, fixed seed 42 (reproducible) |
| Limitations | No reflections, blocking, tilt or ambient light; 4 LEDs only; receiver height fixed |

To use a real dataset instead, see "Using real data" below.

## Files
- `app.py` - the dashboard (6 pages)
- `train_model.py` - validation, split, cross-validation, model selection, evaluation, saving
- `data_utils.py` - synthetic data generator and dataset validation
- `data/` - dataset CSV
- `models/` - `position_model.joblib` (full scikit-learn Pipeline), `metadata.json`, `test_predictions.csv`
- `requirements.txt`, `run_windows.bat`, `.streamlit/config.toml`

## ML workflow
1. Load CSV and validate required columns; coerce to numeric; drop missing and duplicate rows.
2. 80/20 train/test split (seed 42). The test split is not used for any decision.
3. Five candidates (Linear Regression baseline, KNN, Random Forest, Extra Trees, MLP), each in a Pipeline of
   `log1p` -> `StandardScaler` -> model, evaluated with 5-fold CV on the training split.
4. Selection criterion: lowest mean cross-validated Euclidean position error.
5. The selected pipeline is fitted on the training split and evaluated once on the test split (MAE, RMSE, R², position error).
6. The pipeline is saved; the dashboard loads it and calls `predict` on the DataFrame built from the entered values,
   with columns in the same order as training.

## Windows setup (step by step)
1. **Install Python 3.10 or newer** from https://www.python.org/downloads/ . On the first installer screen tick
   **"Add python.exe to PATH"**, then Install.
2. **Open the project folder:** unzip the project, open the folder in File Explorer, click the address bar, type `cmd`, press Enter.
3. **Install dependencies:**
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. **Train the model** (do this on your machine so the saved model matches your scikit-learn version):
   ```
   python train_model.py
   ```
5. **Launch the dashboard:**
   ```
   streamlit run app.py
   ```
   It opens at http://localhost:8501 . (Shortcut: double-click `run_windows.bat` to do steps 3 to 5.)
6. **Test that inputs are really used:** open *Position Prediction*, enter `50 20 20 10` and press
   *Predict Indoor Position* (result is near the lower-left, about X 1.5, Y 1.5). Then enter `10 20 20 50`
   and predict again: the result moves to the opposite side (about X 3.4, Y 3.4). The "exact input values"
   table shows what was sent to the model, and *Prediction history* lists both runs. Changing a box without
   pressing the button does not change the result. *Fill with a random dataset row* then *Predict* shows the
   true position next to the prediction.

## Using real data
Put your CSV in `data/` and run, for example:
```
python train_model.py --csv data\my_data.csv --features L1 L2 L3 L4 --targets X Y --units m --real --source "Citation of the dataset"
```
The dashboard adapts to the feature names, ranges and units found in the data. Signal values must be non-negative.

## Troubleshooting
- *Trained model not found / could not load model*: run `python train_model.py`, or press **Train model now** in the app.
- *`streamlit` is not recognised*: activate the venv (`venv\Scripts\activate`) or use `python -m streamlit run app.py`.
- *Port in use*: `streamlit run app.py --server.port 8502`.
